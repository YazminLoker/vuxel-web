Preguntas frecuentes

Todo lo que necesitás saber antes de crear tu sitio web con VUXEL.

¿El precio incluye dominio y hosting?

El alojamiento web está incluido en nuestras propuestas. El dominio se cotiza por separado según la extensión que elijas (.com, .com.ar, etc.). Te ayudamos con la configuración.

¿Qué es una landing page personalizada?

Una Landing Page Personalizada es una página web de una sola página, diseñada especialmente para tu negocio. En ella podés mostrar quién sos, qué ofrecés, tus trabajos y tus datos de contacto.Es ideal si buscás tener presencia en internet de forma profesional, sencilla y atractiva.

¿Qué es una web personalizada?

Una Web Personalizada es un sitio diseñado y desarrollado a medida, según las necesidades de tu negocio. A diferencia de una Landing Page, puede incluir varias páginas y secciones independientes, permitiéndote organizar mejor tus servicios, productos e información. Es ideal para negocios que necesitan un sitio más completo y con mayores posibilidades de crecimiento.

¿Cuándo necesito contratar Mantenimiento Web?

Cuando ya tenés una página web y necesitás mantenerla actualizada. El mantenimiento te permite modificar textos, imágenes, precios, servicios o información de contacto, además de realizar ajustes y mejoras para que tu sitio siga funcionando correctamente. Es ideal si querés mantener tu web al día sin preocuparte por los cambios técnicos.

¿Puedo elegir el diseño?

Sí. Te presentamos un diseño inicial y podemos hacer ajustes según tus preferencias. También podemos orientarte para lograr un diseño atractivo y funcional.

¿Cuánto tiempo tarda la entrega?

El plazo depende del tipo de sitio web. Una Landing Page Personalizada tiene una entrega estimada de 5 a 7 días hábiles, una vez recibido todo el material necesario. Los proyectos más grandes se presupuestan con sus propios plazos.

¿Puedo pedir modificaciones?

¡Sí! Podés solicitar modificaciones durante el proceso de desarrollo, de acuerdo con las revisiones incluidas en tu propuesta. Los cambios adicionales se presupuestan por separado.

¿Qué tipo de páginas desarrollan?

Diseñamos y desarrollamos Landing Pages y sitios web personalizados para negocios, profesionales y emprendimientos que necesitan presencia online. Nos enfocamos en sitios modernos, visuales y que generen una buena experiencia de usuario.

¿Hacen tiendas online?

No, Actualmente nos especializamos solo en sitios web informativos y de presentación de negocios.

¿El contenido lo proporciono yo?

Sí. Para comenzar necesitamos la información de tu negocio, imágenes, servicios, datos de contacto y logo, si tenés uno. También podemos orientarte para organizar el contenido de tu página.

¿Cómo es el proceso de trabajo?

Primero nos contás tu idea y completás un formulario con la información de tu negocio. Luego definimos el diseño, comenzamos el desarrollo, realizamos las revisiones acordadas y finalmente publicamos tu sitio web.
